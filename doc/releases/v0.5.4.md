# Orbyte v0.5.4

Author: jaswtao · Date: 2026-11-25

## Changes

- Local and remote workspace tabs show where they will land while you drag them.
- Windows terminals reliably receive standalone Escape presses.
- Inline Codex footer warnings no longer trigger false unread indicators.
- Update `cookie` to 0.18.3, `libz-sys` to 1.1.33 and `url` to 2.5.9. [cookie advisory](https://rustsec.org/advisories/RUSTSEC-2026-0594.html) · [libz-sys advisory](https://rustsec.org/advisories/RUSTSEC-2026-0544.html) · [url advisory](https://rustsec.org/advisories/RUSTSEC-2026-0592.html)

## 更新内容

- 拖动本地或远程工作区标签时，显示标签将插入的位置。
- 修复 Windows 终端中单独按 Escape 键可能无效的问题。
- 避免 Codex 页脚的行内警告误触发终端未读提示。
- 将 `cookie`、`libz-sys` 和 `url` 更新至已修复版本。

## Installation and verification

Download `Orbyte_0.5.4_x64-setup.exe` and compare its SHA-256 hash with `SHA256SUMS.txt` before installing.

```powershell
Get-FileHash .\Orbyte_0.5.4_x64-setup.exe -Algorithm SHA256
```

The Windows x64 installer is unsigned and requires Microsoft Edge WebView2 Runtime. Back up application data before upgrading. The tagged workflow runs automated Windows checks before packaging. See the [release checklist](https://github.com/jaswtao/Orbyte/blob/v0.5.4/doc/release-checklist.md) for the full native acceptance matrix and the [v0.5.1 notes](https://github.com/jaswtao/Orbyte/blob/v0.5.1/doc/releases/v0.5.1.md#known-limitations-and-local-data) for existing limitations and data locations.

The release includes matching source, the MIT license, third-party notices and license inventory, and the MPL source archive. The checksum file covers all six accompanying assets.
