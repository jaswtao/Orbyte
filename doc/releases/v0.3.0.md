# Orbyte v0.3.0

Author: jaswtao · Date: 2026-10-29

This release includes the changes since v0.2.0 and the bundled bilingual release notes added after the initial v0.3.0 build. Native installation and desktop acceptance remain incomplete.

## New features and improvements

- **Version and offline release notes:** Settings → About Orbyte shows the installed version and bundled release highlights in Chinese or English, including when offline.
- **Project visibility:** hide projects from the sidebar and use the settings toggle to show hidden projects. Projects with recovered editor drafts remain visible so recovery is accessible.
- **Two file search modes:** Ctrl+P respects ignore rules; Ctrl+Shift+P searches including ignored files. Each mode uses its own cached index, and upgrades preserve existing custom shortcut bindings.
- **Workspace highlight borders:** choose a border color and intensity, preview the result in settings, or reset to the theme default.
- **Sidebar navigation:** project filters wrap onto multiple rows, and vertical project shortcuts reveal the active project in the sidebar. Active sidebar view buttons no longer use a highlight border.

## Fixes

- Restore terminal focus when the application window becomes active and on initial load.
- Trim trailing whitespace from terminal line selections and preserve selection drag anchors when scrollback is trimmed.
- Keep the terminal cursor blinking when the operating system enables reduced motion.

## Release checks and acceptance

The tagged release workflow runs Windows tests, frontend type checking/build, dependency audits, secret/history scans, license verification and Rust 1.90 compatibility checks before packaging.

Manual installation and desktop acceptance are incomplete. Automated checks do not certify the unexecuted scenarios in the [release checklist](https://github.com/jaswtao/Orbyte/blob/v0.3.0/doc/release-checklist.md) and [acceptance record](https://github.com/jaswtao/Orbyte/blob/v0.3.0/doc/next-stage-validation.md). Back up application data before upgrading; this version adds project visibility and shortcut database migrations.

## Installation and verification

Download `Orbyte_0.3.0_x64-setup.exe` and compare its SHA-256 hash with `SHA256SUMS.txt` before installing:

```powershell
Get-FileHash .\Orbyte_0.3.0_x64-setup.exe -Algorithm SHA256
```

The Windows x64 installer is unsigned. Microsoft Edge WebView2 Runtime is required and its setup may download Microsoft components. Git, WSL, Codex and Claude Code are optional external tools and are not bundled. Back up application data before upgrading; native upgrade acceptance has not been completed.

## Known limitations and local data

- Restart restores projects, layouts and file paths. Draft recovery offers the last successfully persisted editor draft; it does not restore running processes or terminal output and cannot guarantee recovery of edits made before the latest draft write.
- UNC/WSL network project directories are unsupported. The text editor and recovery drafts have a 5 MiB limit.
- Windows managed child processes stop with their terminal. Detached WSL processes and Linux services may outlive a terminal session.
- Clipboard screenshots remain in the application cache until manually removed.
- Application data is stored under `%APPDATA%\com.orbyte.desktop\`; clipboard images are under `%LOCALAPPDATA%\com.orbyte.desktop\clipboard-images\`. Back up these directories before deleting data. Uninstall cleanup behavior has not been verified; do not assume uninstall removes user data.
