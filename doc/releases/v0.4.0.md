# Orbyte v0.4.0

Author: jaswtao · Date: 2026-11-02

This release includes the changes since v0.3.0. Native installation and desktop acceptance remain incomplete.

## New features and improvements

- **SSH and SFTP:** save connections, confirm a host key by algorithm and SHA-256 fingerprint, open remote terminals and splits, and browse, upload or download files. Symlinks are shown and not followed.
- **Saved passwords:** store an SSH password in Windows Credential Manager. A standard sudo prompt can submit that password when a physical, unmodified Enter is pressed. Typing manually cancels the offer, and each command line allows at most one automatic submission.
- **Remote projects:** persist project-level terminal tabs and split layouts across connections. Switch projects with Ctrl+Shift+Up/Down and cycle sidebar views with Ctrl+Shift+Left/Right.
- **Directory sync:** when the focused remote prompt is idle, the file panel follows that terminal's directory. Relative SFTP listings resolve to absolute paths.
- **Duplicates and order:** the same local project path can be added more than once. Duplicate a local or remote project, or an SSH connection; copied connections do not copy the saved password. Drag projects and connection names to reorder them.
- **Editing and navigation:** the editor has a context menu for undo, redo, clipboard, find, replace and save. Reveal a file or directory in Explorer, close a tab with the middle mouse button, and press F2 to rename the focused project or tab.

## Fixes

- Keep terminal output that arrives while a session is hidden or falls behind, instead of dropping it. Display recovery pauses while the document is hidden and resumes when the session is visible.
- Preserve tab names when layout saves overlap, and keep the input-method cursor position across display recovery.

## Release checks and acceptance

The tagged release workflow runs Windows tests, frontend type checking/build, dependency audits, secret/history scans, license verification and Rust 1.90 compatibility checks before packaging.

Manual installation and desktop acceptance are incomplete. Automated checks do not certify the unexecuted scenarios in the [release checklist](https://github.com/jaswtao/Orbyte/blob/v0.4.0/doc/release-checklist.md). The isolated OpenSSH probe covers the automated protocol matrix in [SSH protocol probe](https://github.com/jaswtao/Orbyte/blob/v0.4.0/doc/ssh-probe.md). It does not replace installed-app host-key confirmation, a 1 GiB transfer, keepalive timing or reconnect acceptance. Back up application data before upgrading; this version migrates the local database for remote projects, shortcuts and shared project paths.

## Installation and verification

Download `Orbyte_0.4.0_x64-setup.exe` and compare its SHA-256 hash with `SHA256SUMS.txt` before installing:

```powershell
Get-FileHash .\Orbyte_0.4.0_x64-setup.exe -Algorithm SHA256
```

The Windows x64 installer is unsigned. Microsoft Edge WebView2 Runtime is required and its setup may download Microsoft components. Git, WSL, Codex and Claude Code are optional external tools and are not bundled. Back up application data before upgrading; native upgrade acceptance has not been completed.

## Known limitations and local data

- A saved-password submission is triggered by terminal text and cannot verify the prompt's origin. A program that can print in the remote session can imitate the prompt and capture the saved SSH password. Use it only when the session content is trusted.
- SSH accepts OpenSSH Ed25519 and RSA keys, including encrypted keys. It does not support PuTTY `.ppk`, SSH agents, keyboard-interactive/MFA, certificate authentication or `ssh_config` import. A keyboard-interactive-only server fails without sending the password.
- Transfers skip symlinks and special files and do not preserve ownership, ACLs or Unix modes. A disconnected transfer may leave a `.orbyte-transfer-<UUID>.part` file. Its path is shown, and the file panel cannot delete it.
- Restart restores projects, layouts and file paths. Draft recovery offers the last successfully persisted editor draft; it does not restore running processes or terminal output and cannot guarantee recovery of edits made before the latest draft write.
- UNC/WSL network project directories are unsupported. The text editor and recovery drafts have a 5 MiB limit.
- Windows managed child processes stop with their terminal. Detached WSL processes and Linux services may outlive a terminal session.
- Clipboard screenshots remain in the application cache until manually removed.
- Application data is stored under `%APPDATA%\com.orbyte.desktop\`; clipboard images are under `%LOCALAPPDATA%\com.orbyte.desktop\clipboard-images\`. SSH passwords are stored in Windows Credential Manager. Back up application data before deleting it. Uninstall cleanup behavior has not been verified; do not assume uninstall removes user data.
